# 🏥 The Syntax Surgeon

AI Powered Python Code Fixer and Chatbot.

## Features

- Detects Python code automatically
- Fixes syntax errors
- Formats code using Black
- Chatbot interface with Gradio
- Export conversation as TXT and PDF

## Installation

pip install -r requirements.txt

## Run

python app.py

## Tech Stack

Python  
HuggingFace Transformers  
Gradio  
Black Formatter
